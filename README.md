# Data Structures & Algorithms Practice

Welcome to my **DSA Practice** repository! This project contains my implementations of various fundamental Data Structures and Algorithms problems written in **C** and **C++**.

---

## 📌 Topics Covered

- **Basic Programming & Math Logic:**
  - Armstrong Number, Palindrome, Prime Number Check
  - Sum of Digits, Digit Count, Swap Numbers
  - FizzBuzz, Min & Max Digit in Number
- **Pattern Printing:**
  - Centered Pyramid, Inverted Centered Triangle, Right Angle Triangle
  - Diamond, Hollow Square, Hourglass Pattern
- **Arrays & Pointers:**
  - Finding Unique & Duplicate Elements
  - Two-Pointer Approach (Reverse String, Move Zeros to Start/End)
  - Rearranging Elements (Negative to Front, Positive to Back)
  - Pair Sum, Pair Product, Triplet Sum
  - Finding Second Smallest & Min/Max Elements
